# Mochi Squad Profile Templates

Core v0.1 templates:

- `mochi-exec/SOUL.md`
- `mochi-review/SOUL.md`

They are minimal bootstrap files: identity, boundaries, and the required role guide. Detailed workflow rules live in `SKILL.md` and `references/`.

Core setup creates these profiles if missing and skips existing profiles by default. There is no core `mochi-plan` or `mochi-research` profile template.
